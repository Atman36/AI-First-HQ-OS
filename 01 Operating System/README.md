This folder explains how to use HQ as an operating workspace without breaking the existing repository rules.

## Core Rule

The canonical company state still lives in the root files:

- [[now]]
- [[projects]]
- [[routines]]
- [[stack]]

## What This Folder Is For

- Make the repository easier to browse in Obsidian.
- Keep a stable navigation layer.
- Clarify where to write what.

## Writing Rules

- Update `now.md` when the current company focus changes.
- Update `projects.md` when project status or ownership changes.
- Update `routines.md` when operating cadence changes.
- Update `stack.md` when tool boundaries change.
- Use `02 Planning/` for active shared work items.
- Use `03 Notes/` for inbox capture and decision history.
- Use `04 Projects/` for project-specific detail pages.

## Private vs Shared

- Shared company state belongs in this repository.
- Private agent memory belongs outside this repository.
- Future Paperclip agents should point to the same shared files, not duplicate them.
