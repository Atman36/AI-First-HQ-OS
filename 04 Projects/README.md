## Rule

Use project pages for:

- project-local detail that would clutter the root
- local risks and dependencies
- support notes from specialist roles
- implementation context for the current stage
- open project choices that later need a summary in `Decisions.md` or `Open Decisions.md`

## When Adding A Real Project

1. Add a short registry entry to `projects.md`.
2. Create a page here from `90 Templates/Project Intake Template.md`.
3. Keep only the operating truth in tracked files; private technical detail stays outside tracked HQ or under `.hq/` when it is runtime-only.
